    How to get a key or a token
    1. Open the Google Cloud console and create a project with billing turned on.
    2. Turn on Maps JavaScript API, Places API (New), Directions API and Distance Matrix API.
    3. Create an API key and restrict it to this website's address.

    The key stays in this browser. A site owner can set one for everyone in config.js.

    For a OneMap token, register for a free account at onemap.gov.sg and request one with your email and password. Tokens last three days. A site owner can run scripts/onemap-proxy.mjs instead, so visitors never need one.

    Your score, home and list are saved in this browser only.
